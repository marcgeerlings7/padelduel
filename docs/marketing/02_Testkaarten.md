# Testkaarten — wat telt als "werkt"? (vooraf vastleggen)

**Beslissing in één zin:** draai de **ambassadeurs** en de **referral-loop** vanaf het begin samen
(ze kosten vooral tijd), en zet **ads** pas in als testronde vanaf week −4, alleen als de teller
achterloopt.

Uitgangspunten (pas aan als ze niet kloppen):
- Doel **D** = unlock-drempel: 1.000 (metropool) of 500 (middelgrote regio) — zie het marktonderzoek §4.
- Wervingsperiode: 8 weken (fase 1+2 in het draaiboek).
- PadelDuel is gratis → er is geen omzet per klant. De "maximale kosten per duo" worden daarom
  afgeleid uit **budget ÷ het aantal duo's dat een kanaal moet leveren**.
- **Aanname:** de capaciteit is 1 persoon × ~8 uur/week (niet door de PO opgegeven; pas aan).

Alle lijnen hieronder zijn **voorstellen**, afgeleid uit het doel. Zet ze vast vóór de start.

---

## Test 1 — Ambassadeurs (fase 1, week −8 t/m −5)

| | |
|---|---|
| Wat | 25 ambassadeurs (trainers, organisatoren van WhatsApp-ladders) werven duo's met een persoonlijke link/code |
| Deeldoel | Fase 1 = 25% van D → 250 duo's (bij D = 1.000) of 125 (bij D = 500) |
| Rekensom | 250 ÷ 25 ambassadeurs = **10 duo's per ambassadeur** (D = 500: 5) |
| **Pass** | Op de leesdatum hebben ≥ 13 van de 25 ambassadeurs elk ≥ 10 duo's binnengebracht (D = 500: ≥ 5) |
| **Stop** | < 6 ambassadeurs met ≥ 4 duo's → stop met werven van nieuwe ambassadeurs; benader in plaats daarvan clubs direct |
| Leesdatum | einde week −5 |
| Caps | Kosten: merchandise ~€20–40 p.p. (= €500–1.000 totaal). Tijd: 3 u/week (werven + briefen + check-ins) |
| Wekelijks bijhouden | duo's per ambassadeurscode, aantal actieve ambassadeurs |

## Test 2 — Referral-loop + club-battle (fase 1+2, week −8 t/m −1)

| | |
|---|---|
| Wat | Elke ingeschreven speler nodigt partners uit (multi-duo); teller per regio + per club |
| Rekensom | Na fase 1 (250 duo's ≈ 350 spelers) moeten er nog 750 duo's bij in 4 weken → **~190 duo's/week** |
| Maat | Nieuwe duo's per week die via een uitnodigingslink binnenkomen ÷ het aantal ingeschreven spelers aan het begin van die week |
| **Pass** | In week −4 komen er ≥ 190 nieuwe duo's bij (D = 500: ≥ 95) |
| **Stop/bijsturen** | < 95 nieuwe duo's in week −4 (D = 500: < 48) → activeer de stopregel uit het marketingplan (drempel verlagen) of start Test 3 |
| Leesdatum | einde van elke week vanaf week −4 |
| Caps | €0 cash. Tijd: 2 u/week (mijlpaal-posts, club-battle-updates) |

## Test 3 — Meta/Instagram-ads, straal 25 km (alleen als Test 2 achterloopt, week −4 t/m −2)

| | |
|---|---|
| Wat | Ads met de teller ("nog 312 duo's tot Zwolle live gaat") naar de inschrijfpagina |
| Rekensom | Ads moeten het gat dichten; stel 200 duo's bij €2.500 → **max €12,50 per duo** (bij €1.000: €5,00) |
| Eerste ronde | €300 |
| **Pass** | De eerste €300 levert ≥ 24 nieuwe duo's op (300 ÷ 12,50) → schaal op naar het volledige budget |
| **Stop** | ≤ 12 duo's voor €300 → stoppen, het budget naar Ladder Day/prijzen |
| Leesdatum | 7 dagen na de start (aanmelden gebeurt direct, er is geen trialperiode) |
| Caps | Max. €2.500 totaal, 1 u/week |
| Meten | Aparte link met `?ref=meta`; tel alleen voltooide duo's (beide spelers bevestigd) |

## Uren en cash per week (controle)

| Week | Uren | Cash |
|---|---|---|
| −8 t/m −5 | 3 (T1) + 2 (T2) = 5 | merchandise, eenmalig €500–1.000 |
| −4 t/m −2 | 2 (T2) + 1 (T3) + 2 ambassadeur-check-ins = 5 | max. €2.500 (T3) |
| −1 | 2 (T2) + Ladder Day-voorbereiding | event €750–1.500 |

Past binnen ~8 u/week. **Risico:** Ladder Day kost in week −1 en week 0 meer tijd dan dat.

## Wat er nodig is om te kunnen meten
- **Optie A (in de app, PO-akkoord nodig):** referral-tracking + ambassadeurscodes (marketingplan §8, punt 3).
- **Optie B (zonder code, eerst testen):** een wachtlijstformulier (bv. Tally/Google Forms) met de
  velden "duo-naam, partner, club, via wie (code)"; de teller wordt handmatig dagelijks bijgewerkt
  op de pre-launchpagina/Instagram. Goedkoop om de vraag te valideren vóórdat je bouwt.

**Let op met prijzen:** een prijs voor "het duo dat de meeste duo's binnenhaalt" is een
promotieactie. Houd de spelregels kort en openbaar, en laat de prijs niet afhangen van een
review of positieve post. (Geen juridisch advies.)
